# Iteration 02 — friendlier teaching voice

## Karen’s requested change

Keep the existing italic comments, which she liked, and make the explanations in each section friendlier or funnier for the intended audience.

## Delivered copy changes

- Rewrote the main teaching paragraph, everyday example, introduction to the illustration, and connecting explanation in all 25 chapters.
- Made glossary explanations more conversational while retaining the financial concepts. The expert label “Value of liquidity” describes the existing explanation in plain language.
- Used simple playful language for children, conversational language for teens and college students, warm everyday language for post-college learners, and restrained wit for the expert course.
- Kept all 25 original italic comments exactly as written.
